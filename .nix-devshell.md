# Nix Devshell for Percy CLI

This project includes a Nix flake that provides a development environment with all dependencies needed to build the Linux ARM64 executable.

## Quick Start

1. **Enter the devshell:**
   ```bash
   nix develop
   ```

2. **Build the Linux ARM64 executable:**
   ```bash
   ./scripts/executable-local-linux.sh
   ```

## What's Included

The devshell provides:
- **Node.js 14** (required for pkg compatibility)
- **npm** and **yarn**
- **gsed** (GNU sed)
- **zip** (for creating archives)
- **file** (for binary verification)

The `pkg` tool will be automatically installed via npm when you enter the shell.

## Requirements

- Nix with flakes enabled
- If flakes aren't enabled, run: `nix --experimental-features "nix-command flakes" develop`
